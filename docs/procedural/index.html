Neural Path Explorer · ID граф

ID адресуются процедурно. Вершины и направленные связи не хранятся заранее.

Структурный граф строго синтетический: локальные связи и редкие пространственные проекции между соседними HRA-областями, без биологических синаптических данных. Смена общего количества перенумеровывает глобальные ID.

Режим проводящих трактов

Трактовые линии — условные трассы через пространственные ячейки HRA, не реконструированные аксоны. Белое вещество не получает фиктивных тел нейронов.

Нейронные квоты 283 областей — модельные оценки. Опорные ~69 млрд мозжечковых, ~16 млрд корковых и ~0,73 млрд других нейронов взяты из литературы; детализация внутри групп распределена по приблизительным геометрическим объёмам NeutralLab V5, не по экспериментальным подсчётам каждой области.
