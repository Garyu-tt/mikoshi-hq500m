# HQ500M · 3D Connectome Render R02

Actual WebGL/SwiftShader 3D screenshots from the original HQ500M Q0.8 deterministic graph sample (not generated with text-to-image AI).

- [Oblique / cover PNG](HQ500M-connectome-R02.png) — primary Reddit image, 1800×1400.
- [Frontal PNG](HQ500M-connectome-R02-front.png) — alternate camera, 1800×1400.
- [Provenance manifest](HQ500M-connectome-R02-manifest.json) — model/source hashes, sample size and renderer notes.
- [WebGL scene source](HQ500M-connectome-R02-renderer.html) — requires original `web/vendor` modules and R02 `web/assets` files in matching paths.

Source geometry comes from the original HQ500M R02 GLB. The display draws **50,400 verified Q0.8 sample edges** among **5,040 sampled source addresses**. A 500 million-neuron virtual *address space* is not the same as 500 million reconstructed or active neurons in these images. Bezier-like visual fiber bends preserve endpoints and introduce no extra network connections. The three-dimensional layout and anatomical shell are **synthetic, not measured human neuroanatomy**.
