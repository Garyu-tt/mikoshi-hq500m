# HQ500M data-driven renders · R01

These PNGs are **actual CPU/SwiftShader WebGL screenshots**, not AI-generated illustrations:

- [HQ500M-connectivity-R01.png](HQ500M-connectivity-R01.png): graph-focused display using the genuine deterministic HQ500M Q0.8 `edge()` mapping.
- [HQ500M-anatomy-R01.png](HQ500M-anatomy-R01.png): original R02 procedural whole-body GLB with the same sampled graph projection.

The model defines **500,000,000 virtual neuron addresses** and 32 potential outgoing edges per neuron. **This poster renders a deterministic sample** of 5,040 source neuron addresses and 50,400 edges (30,240 local + 20,160 projected). Neither image depicts 500 million simultaneously materialized or active neurons.

**Scientific limitation:** the 3D node coordinates are a deliberately synthetic per-region projection. The original whole-body anatomical geometry is also a procedural, unvalidated test asset. This is *not* a measured human connectome, an anatomical scan, nor evidence of human-like intelligence.

Provenance: [poster-R01-manifest.json](poster-R01-manifest.json), including the Q0.8 generator SHA-256 and rendered PNG checksums.
