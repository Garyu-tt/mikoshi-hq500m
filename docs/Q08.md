## Limitations

1. This is a selected deterministic toy connection, **not** independently sampled proof of general learning.
2. The virtual 500M neurons and potential 16B edges are not materialized or simultaneously simulated.
3. There is no evidence of biological validity or emergent cognition.
4. This public source snapshot excludes raw GPU reports and binary checkpoints; claims above are transcribed from the original project notes, not rerun by GitHub CI.
5. The simulation depends on eight CUDA GPUs; CPU-only inspection supports wiring verification, not neural dynamics.

For raw-result verification on a compatible host, use `tests/hq500m_q08_audit.py` with four control reports and one checkpoint-resumed report.
