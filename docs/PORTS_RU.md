# HQ500M — куда подключать органы чувств и игры

Это **условная карта функциональных интерфейсов**, а не реконструкция анатомии человека. Виртуальных адресов нейронов фиксированно 500 миллионов. Для игрового режима по умолчанию реально работает **896 нейронов**, по 128 в семи областях; при желании — до 7168.

## Куда подключать сигналы

| Сигнал игры | Название входа | Адреса нейронов |
| --- | --- | --- |
| Левый глаз | `eye_left` | 344999936–344999947 |
| Правый глаз | `eye_right` | 344999948–344999959 |
| Левое ухо | `ear_left` | 344999960–344999971 |
| Правое ухо | `ear_right` | 344999972–344999983 |
| Прикосновения / столкновения | `touch` | 344999984–344999995 |
| Препятствие слева | `obstacle_left` | 344999996–345000007 |
| Препятствие справа | `obstacle_right` | 345000008–345000019 |
| Еда / цель | `food` | 345000020–345000031 |
| Восходящая обратная связь от тела | `spinal_sensory` | 434999296–434999307 |
| Усталость | `fatigue` | 434999308–434999319 |
| Равновесие | `balance` | 224999424–224999435 |
| Новизна / событие | `novelty` | 294999040–294999051 |
| Запах | `smell` | 469999616–469999627 |
| Голод | `hunger` | 469999628–469999639 |
| Угроза | `threat` | 469999640–469999651 |

**Глаза:** обработка настоящего изображения *не* реализована; игровой адаптер должен сам извлечь два числа (от -1 до +1) из камеры/кадра. В нашей условной схеме вход идёт в «таламус».

**Спинной мозг:** отдельную модель спинного мозга мы не публикуем и не симулируем в этой игрушке. Вход `spinal_sensory` — восходящий сигнал о состоянии тела, выходы в «стволе мозга» — условные нисходящие команды аватару.

## Откуда брать команды движения

| Команда | Адреса | Что делать в игре |
| --- | --- | --- |
| `forward` | 434999344–434999355 | идти вперёд |
| `left` | 434999356–434999367 | повернуть влево |
| `right` | 434999368–434999379 | повернуть вправо |
| `retreat` | 434999380–434999391 | отступить |
| `interact` | 0–11 | взаимодействовать |
| `idle` | 394999808–394999819 | бездействовать |

Код намеренно содержит **явные искусственные проводки** сенсор→мотор: например, препятствие слева усиливает выход поворота направо; сигнал об угрозе усиливает отступление. Это демонстрация подключения, **не человеческий коннектом**.

## Самый простой запуск

```bash
python3 -m hq500m demo
python3 -m hq500m ports
python3 examples/simple_game.py
```

Встраивание в Python-игру:

```python
from hq500m import Brain

brain = Brain()
reply = brain.step({"eye_left": 0.8, "obstacle_left": 0.9,
                    "spinal_sensory": 0.3, "reward": 0})
print(reply["action"])
```

Если движок написан не на Python, подойдёт `python3 -m hq500m jsonl` (строки JSON по stdin/stdout) или `python3 -m hq500m server` (локальный HTTP). Маршруты: `GET /v1/ports` и `POST /v1/step`. Все сигналы ограничены диапазоном [-1,1], `reward` оценивает **предыдущую** команду. Управление физикой, камерой и столкновениями остаётся на стороне игры.
